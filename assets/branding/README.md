# Oslo Offsite icon

`oslo-offsite-icon.png` is the original opaque 1254 × 1254 PNG generated with the built-in image-generation tool on 2026-09-09, at the user's request. Expo generates the platform-specific sizes during prebuild. Android uses Expo's single-image icon path, which keeps the image uncropped; no separate adaptive or monochrome layer is configured.

Prompt:

> Use case: logo-brand. Create one finished square mobile app icon for an app called Oslo Offsite, a small team's September gathering in Oslo. The icon should feel calm, friendly and distinctly Scandinavian. A bold, minimal geometric illustration of Oslo's sloping white opera-house roof above a deep blue fjord, with one warm low sun, forming a compact memorable symbol. Clean flat graphic shapes with a subtle material finish, strong contrast, no tiny details. Deep midnight blue, clear fjord blue, warm ivory and a restrained coral sun. Single centered composition, generous margins: all essential artwork inside the central 60 percent of the square so it survives circular and squircle masks. Full-bleed opaque background, square corners. No text, letters, numbers, Expo logo, border, watermark, device mockup or multiple variants. Output the actual high-resolution icon artwork, 1024 by 1024.

The generated image is larger than the requested size; Expo performs the required format/size conversion. A subsequent transparent-layer attempt had a baked-in checkerboard and was rejected. It is not included in the project.
